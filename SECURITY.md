# Security policy

## Supported versions

`DotnetOpenEhr` is pre-1.0 (`0.x` beta train). No long-term
support guarantees are made for these releases; security fixes will
land in the next published beta and any tagged `0.x` release in
flight.

## Reporting a vulnerability

If you believe you have found a security issue in this SDK, please
**do not** open a public GitHub issue. Instead, contact the repo
owner privately via the email associated with the `GinoCanessa` GitHub
account.

You can expect:

- An acknowledgement within a few business days.
- Coordination on a fix and disclosure timeline.
- Credit in the changelog once a fix is published, unless you ask
  otherwise.
